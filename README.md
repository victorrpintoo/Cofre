# 🗝️ Cofre

*Tu oro, bajo llave.*

Una app sencilla para anotar ingresos y gastos, ponerte presupuestos por categoría y seguir tus metas de ahorro, en Lempiras.

**Úsala aquí:** https://victorrpintoo.github.io/cofre/

- 📱 Pensada para el celular: se puede instalar con "Agregar a pantalla de inicio" y funciona sin internet.
- 🔒 Tus datos se guardan **solo en tu dispositivo**. No se envían a ningún servidor.
- 💾 Haz respaldos desde el menú ☰.

Hecha con ayuda de [Claude Code](https://claude.com/claude-code).
